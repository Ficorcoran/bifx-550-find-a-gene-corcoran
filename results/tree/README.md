# results/tree/

Structure prediction and comparison for Step 7.

MSA outputs were aligned using MEGA12. Optimal model was determined using MEGA12's 'Find Best Model' feature with the following parameters:

Statistical Method: Maximum Likelihood

Tree to Use: Automatic (Neighbor-joining tree)

Approach: Full (slow)

Substitution Type: Amino Acid

Gaps/Missing Data: Use all sites

Branch Swap Filter: None
